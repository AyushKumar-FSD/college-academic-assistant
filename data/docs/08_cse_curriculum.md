# B.Tech Computer Science & Engineering - Semester-wise Courses (2023 scheme, NMAMIT Nitte)
Source: https://nitte.edu.in/nmamit/syllabus/ndu/2023-27/B.Tech._CS_Regulations_2023.pdf

Course type codes: BSC basic science, ESC engineering science, PCC professional core, IPCC integrated professional core (theory + lab), PEC professional elective, OEC open elective, HSMC humanities, AEC ability enhancement, MNC mandatory non-credit, VEC vocational, UCC university core. Every credited course is 50 CIE + 50 SEE marks.

## First and second semester (taken in either order)
Set A: Calculus and Differential Equations (3 credits), Quantum Computing and Modern Physics (4), Introduction to Python Programming (3), Basic Electronics (3), Fundamentals of Cyber Security (3), Technical English (2), Mathematics with MATLAB (1), Constitution of India (non-credit). Total 19 credits.
Set B: Discrete Mathematics and Transform Techniques (4), Materials Chemistry for Computer Systems (4), Applied Digital Logic Design (3), Introduction to C Programming (3), Basic Electrical Engineering (3), IT Skills (2), Biology for Engineers (1), Engineering Visualization (1), Environmental Studies (non-credit). Total 21 credits. Internship-I (2 credits) is done in these two semesters and graded in the 4th semester.

## Third semester (20 credits)
Statistics and Probability Theory (3), Data Structures (IPCC, 4), Object Oriented Programming (IPCC, 4), Computer Organization and Architecture (3), Front End Web Development (3), Data Analysis Using R Programming (1), Universal Human Values (1), Innovations and Design Thinking (1), Kannada (non-credit).

## Fourth semester (23 credits)
- Linear Algebra and its Applications (BSC, 3 credits) - short name LAA
- Design and Analysis of Algorithms (IPCC, 4 credits) - short name DAA
- Microprocessor and Embedded Systems (IPCC, 4 credits) - short name MP
- Software Engineering and Project Management (PCC, 3 credits) - short name SEPM
- Database Management Systems (PCC, 3 credits) - short name DBMS
- Database Management Systems Lab (1 credit)
- Enhancing Self Competence (HSMC, 2 credits)
- Python Programming with Data Science (department vocational course, 1 credit)
- Essence of Indian Culture (HEC, non-credit)
- Internship-I result (2 credits, activity-based internship of 2 weeks)

## Fifth semester (20 credits)
Computer Network and Communication (IPCC, 4), Operating Systems (IPCC, 4), Theory of Computation (3), Java and Spring Framework lab (1), Professional Elective-1 (3), Introduction to IPR (1), Program-specific AEC Back End Development (2) or Research Methodology, Social Connect and Responsibility (1), Employability Skill Development (1). Electives start from the 5th semester.

## Sixth semester (21 credits)
Machine Learning (IPCC, 4), Compiler Design (3), Compiler Design Lab (1), Professional Elective-II (3), Professional Elective-III (3), Open Elective-I (3), Management and Entrepreneurship (3), Life Skills and Personality Development (1). Value added course: Introduction to DevOps (PP/NP).

## Seventh semester (20 credits)
Computer Graphics and Visualization (IPCC, 4), Mobile App Development lab (1), Professional Elective-IV (3), Professional Elective-V (3), Open Elective-II (3), Financial Management (3), Indian Knowledge Systems (1), Major Project Phase I (2).

## Eighth semester (16 credits)
Internship-II (8 credits, total of 8 weeks done in earlier vacations) and Major Project Phase II (8 credits).

## Degree structure
Suggested credit ranges: Basic Science 18-23, Engineering Science 10-15, Emerging Technology 3-5, Programming Language 3-5, Professional Core 52-58, Professional Electives 12-18, Open Electives 6, Humanities and Management 9-15, Ability Enhancement 9, Project work 10-12, Internship 8-12. Total minimum credits to be earned: 160.
